## 5. ESTRATEGIA Y CALENDARIO SEMANAL

### Estructura de publicaciones (Lunes a Viernes)
| Día | Tema | Ejemplo |
|-----|------|---------|
| Lunes | Sistema #1 | REDIL o AulaPro |
| Martes | Consejo/Valor | "3 errores de inventario que te cuestan dinero" |
| Miércoles | Sistema #2 | ContaPro o InvenPro |
| Jueves | IA/Automatización | Neura o n8n |
| Viernes | Caso/Resultados | Testimonios, LicitrackGT, casos de éxito |

### Reglas de oro
1. **Cada post termina con un CTA** (WhatsApp + link)
2. **Publica historias diarias** con tips rápidos y detrás de cámaras
3. **Responde TODOS los comentarios** (el algoritmo lo premia)
4. **Reutiliza cada sistema cada 3-4 semanas** con ángulo distinto
5. **Video > imagen**: los reels/cortos con demo del sistema convierten más

### Secuencia de venta por mensaje directo (DM)
```
1er mensaje: "¡Hola [nombre]! Gracias por contactar a Total App GT. 
¿Buscas un sistema para [iglesia/contabilidad/inventarios/etc]?"

2do: Envía un video de 30s mostrando el sistema

3ro: "Con [sistema] podrías [beneficio principal]. 
¿Te gustaría una demostración gratis por WhatsApp?"

4to: Agenda la demo. Al terminar, envía propuesta con precio.
```
